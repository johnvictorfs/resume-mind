# Resume Mind

Create or upgrade your Resume with a user-friendly interface, with the optional help of AI.

## Development

- Requirements

  - [bun](https://bun.sh)

- Setup

  ```bash
  # Install dependencies
  bun install

  # Setup environmant variables in .env file
  cp .env.example .env # then edit with prefered editor

  # Setup the database
  bun db:push
  ```

- Start dev server

  ```bash
  bun dev
  ```
